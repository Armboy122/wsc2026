SIMULATED BACKEND · ข้อมูลจำลอง

ยินดีต้อนรับสู่ระบบสาธิต

หน้านี้เชื่อมต่อกับ ข้อมูลจำลอง (Simulated Backend) เท่านั้น — ไม่มีการเข้าถึงข้อมูลลูกค้าจริง ระบบชำระเงินจริง หรือระบบการผลิตของ กฟภ. ไม่ว่ากรณีใด ๆ

การกระทำที่มีผลต่อข้อมูล (แจ้งไฟดับ) จะแสดงตัวอย่างให้ตรวจสอบก่อน และเกิดขึ้นได้เฉพาะเมื่อคุณกด ยืนยัน เท่านั้น

เริ่มต้นด้วยปุ่มสถานการณ์สาธิตด้านล่าง หรือพิมพ์คำถามของคุณเอง

การสนทนานี้เป็นการสาธิตบนข้อมูลจำลองทั้งหมด · ไม่มีการแสดงลำดับความคิด (chain-of-thought) ของโมเดล

การตรวจสอบ (Trace)

— ยังไม่มีรอบการทำงาน —

    ยังไม่มีเหตุการณ์ — ส่งข้อความเพื่อเริ่มต้น

    แสดงเฉพาะเหตุการณ์ตามสัญญา (chat / llm / tool / action) ซึ่งระบบหลังบ้านปิดบังข้อมูลอ่อนไหวก่อนจัดเก็บแล้ว — แผงนี้ไม่แสดง chain-of-thought ของโมเดลภายใต้ทุกเงื่อนไข
