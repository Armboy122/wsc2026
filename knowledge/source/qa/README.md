# Approved Q&A source

ไดเรกทอรีนี้รองรับ Q&A ที่ผ่านการอนุมัติแล้วในรูปแบบ DOCX และเป็นส่วนหนึ่งของ `KNOWLEDGE_SOURCE_ROOT` ที่ Document Router อ่านแบบ recursive

## รูปแบบที่แนะนำ

- หนึ่งหัวข้อ Q&A ต่อหนึ่งไฟล์ เพื่อให้ Router เลือกคำถามที่มีความหมายใกล้เคียงได้แม่นยำ
- ย่อหน้าแรกเป็นคำถามหลักและใช้เป็นชื่อเอกสาร เช่น `ถาม: ผู้เช่าบ้านขอใช้ไฟฟ้าใหม่ได้หรือไม่`
- ย่อหน้าถัดไปเป็นคำตอบที่ได้รับอนุมัติ
- ระบุแหล่งอ้างอิง วันที่ตรวจสอบ และขอบเขตหรือข้อยกเว้นไว้ในเอกสาร
- ชื่อไฟล์ควรสื่อหัวข้อและไม่ใส่ข้อมูลส่วนบุคคล

## นโยบาย

- วางเฉพาะ Q&A ที่เจ้าของข้อมูลหรือผู้มีอำนาจอนุมัติแล้ว
- ห้ามใส่ raw chat, ข้อมูลส่วนบุคคล หรือคำตอบที่โมเดลสร้างเอง
- หากคำตอบเปลี่ยน ต้องแทนที่เอกสารด้วยเวอร์ชันที่อนุมัติแล้วและนำเวอร์ชันเก่าออก
- `README.md` นี้ไม่ถูกนำไปใช้เป็นแหล่งความรู้ เพราะ runtime อ่านเฉพาะไฟล์ `.docx`
- Q&A ทุกคำตอบยังต้องผ่านการตรวจ citation แบบเดียวกับเอกสารทางการ
