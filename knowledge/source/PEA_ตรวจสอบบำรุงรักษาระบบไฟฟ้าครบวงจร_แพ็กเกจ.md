## 3. ฐานข้อมูลความรู้สำหรับระบบ RAG (RAG Knowledge Base)

### 3.1 ภาพรวมและวัตถุประสงค์ (Overview & Objectives)

บริการบำรุงรักษาเชิงป้องกัน (Preventive Maintenance) แบบแพ็กเกจสุดคุ้ม ครอบคลุมทั้งสายส่ง สายจำหน่าย สถานีไฟฟ้า หม้อแปลง ตู้ MDB และจุดต่อไฟฟ้า เพื่อสร้างความมั่นคงในระบบไฟฟ้า ลดโอกาสไฟฟ้าดับ และยืดอายุการใช้งานของอุปกรณ์

### 3.2 คุณสมบัติผู้ขอใช้บริการและเงื่อนไข (Eligibility & Requirements)

สถานประกอบการที่มีหม้อแปลงไฟฟ้าและตู้สวิตช์บอร์ด MDB เป็นของตนเอง

### 3.3 เอกสารและหลักฐานที่ต้องจัดเตรียม (Required Documents)

1. แผนผัง Single Line Diagram 2. จำนวนและขนาดหม้อแปลง 3. ประวัติการบำรุงรักษาครั้งล่าสุด

### 3.4 ขั้นตอนการดำเนินการผ่านระบบออนไลน์ (Step-by-Step Guide)

1. เข้าเว็บไซต์ https://sabuyservice.pea.co.th/service/67683d68-b7e1-4065-1405-08dcb7573509
2. เลือกแพ็กเกจที่ตรงกับขนาดหม้อแปลงของท่าน (Package 1-4)
3. กรอกข้อมูลสถานที่ติดต่อและกดยื่นคำขอรับบริการ
4. วิศวกร กฟภ. นัดหมายวันเข้าตรวจสอบและดับไฟเพื่อบำรุงรักษา
5. ส่งมอบรายงานผลการบำรุงรักษาเชิงวิศวกรรมพร้อมใบรับรองความปลอดภัย

### 3.5 ข้อมูลทางเทคนิค ค่าธรรมเนียม และข้อกำหนด (Technical & Pricing Details)

ราคาแพ็กเกจมาตรฐาน กฟภ.:
- Package 1: หม้อแปลงรวมไม่เกิน 2 เครื่อง ขนาดไม่เกิน 1,500 kVA -> ราคา 35,000 บาท
- Package 2: หม้อแปลงรวมไม่เกิน 2 เครื่อง ขนาดไม่เกิน 500 kVA -> ราคา 25,000 บาท
- Package 3: หม้อแปลงรวมไม่เกิน 250 kVA -> ราคา 20,000 บาท
- Package 4: หม้อแปลงรวมไม่เกิน 50 kVA -> ราคา 10,000 บาท
ขอบเขตงาน: บำรุงรักษาอุปกรณ์แรงสูง, แก้ไขจุดร้อนด้วยไมโครโอห์มมิเตอร์, ตรวจสอบและแก้ไขค่ากราวด์, บำรุงรักษาหม้อแปลง, บำรุงรักษาตู้ MDB, ตัดกิ่งไม้ใกล้แนวสาย, ตรวจสอบ Load Profile และรายงานทางวิศวกรรม
