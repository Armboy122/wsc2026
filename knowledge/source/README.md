# ไดเรกทอรีเอกสารส่งออก PEA ที่เชื่อถือได้

ไดเรกทอรีนี้เป็นส่วน **เดียว** ของคลังความรู้ที่ Document Router เลือกเอกสารได้
ใน runtime

นโยบาย (มีความสำคัญต่อความปลอดภัย):

- ให้วางเฉพาะ **เอกสารส่งออก PEA ที่เชื่อถือได้และหัวหน้าทีมอนุมัติแล้ว** ที่นี่
- repository นี้มีเอกสาร PEA ที่ผ่านการอนุมัติแล้วสำหรับ runtime เท่านั้น; ข้อเท็จจริงต้องมาจากเอกสารต้นทางที่ตรวจสอบได้ ไม่ใช่จากความจำของโมเดล
- ห้ามเพิ่มเนื้อหา “PEA” ที่สร้างโดยโมเดล เนื้อหาตัวอย่าง หรือเนื้อหาสาธิตที่นี่ เอกสารสรุปต้องระบุแหล่งอ้างอิงทางการและวันที่ตรวจสอบเสมอ
- ไฟล์นี้เป็นเอกสารประกอบ ไม่ใช่เนื้อหาความรู้ จึงถูกตัดออกจากการเลือก เช่นเดียวกับ `README.md` และไฟล์ข้อมูลกำกับทุกไฟล์

หากไม่มีเอกสารที่ครอบคลุมคำถาม Document Router จะไม่เลือกเอกสารใด และ `knowledge_tool.search` จะไม่ส่งหลักฐาน
