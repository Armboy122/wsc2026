# Knowledge alias rules

ไฟล์ Markdown หนึ่งไฟล์ต่อหนึ่ง intent สำหรับจับคู่คำพูดของผู้ใช้กับเอกสาร
PEA ที่ได้รับอนุมัติแล้วใน `knowledge/source/` ไฟล์เหล่านี้เป็น configuration
ของการเลือกเอกสารเท่านั้น ไม่ใช่หลักฐานและจะไม่ถูกส่งให้โมเดลใช้ตอบคำถาม

## รูปแบบ

```md
---
id: lowercase-kebab-case
aliases:
  - คำที่ผู้ใช้อาจพิมพ์
sourceIds:
  - PEA_ชื่อเอกสารที่มีอยู่จริง.md
---

# ชื่อ intent

คำอธิบายสำหรับผู้ดูแล
```

กฎที่เพิ่มใหม่ต้องมี `id` ไม่ซ้ำ, alias ไม่ซ้ำกับไฟล์อื่น และอ้าง `sourceIds`
ที่มีอยู่จริงใน `knowledge/source/` เท่านั้น ระบบตรวจความถูกต้องเมื่อสร้าง
Knowledge backend; configuration ที่ผิดจะไม่ถูกใช้

เพิ่มคำเฉพาะเมื่อยืนยันความหมายจากเอกสาร PEA แล้ว ห้ามเพิ่มคำกำกวม เช่น
`เปลี่ยนมิเตอร์` ลงใน intent ขอใช้ไฟฟ้าใหม่ เพราะอาจหมายถึงการเปลี่ยนขนาด
มิเตอร์ มิเตอร์ชำรุด หรือมิเตอร์ TOU
